VAANIAI - SUPABASE SETUP (TAMIL QUICK GUIDE)
===========================================

IMPORTANT:
- Supabase Secret key, Gnani key, Gemini key yaarukkum share panna vendam.
- Secret key backend/.env mattum. Frontend .env.local-la poda koodathu.

STEP 1 - SUPABASE SQL
---------------------
1. Supabase Dashboard -> unga VaaniAI project open pannunga.
2. Left menu -> SQL Editor -> New query.
3. Indha project-la irukkura supabase_schema.sql file open pannunga.
4. Full SQL copy panni SQL Editor-la paste pannunga.
5. RUN click pannunga.
6. Table Editor-la public.interviews table create aagirukka check pannunga.

STEP 2 - SUPABASE KEYS
----------------------
Supabase Dashboard -> Settings -> API Keys (or Connect dialog).

Copy these:
A) Project URL: https://YOUR_PROJECT_REF.supabase.co
B) Publishable key: sb_publishable_...
C) Secret key: sb_secret_...

Secret key backend-only. Browser/frontend/GitHub-la poda vendam.
If dashboard only legacy keys show pannina:
- anon key = publishable key field
- service_role key = backend secret key field

STEP 3 - BACKEND ENV
--------------------
backend/.env file create pannunga (already irundha edit pannunga).
Existing GNANI_API_KEY and GEMINI_API_KEY values preserve pannunga.
Add:

SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
SUPABASE_SECRET_KEY=sb_secret_...
REQUIRE_AUTH=true
FRONTEND_ORIGINS=http://localhost:5173,http://127.0.0.1:5173

STEP 4 - FRONTEND ENV
---------------------
frontend/.env.local file create pannunga:

VITE_API_BASE_URL=http://127.0.0.1:8000
VITE_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...

Inga secret key use panna koodathu.

STEP 5 - SUPABASE EMAIL AUTH URL
--------------------------------
Supabase Dashboard -> Authentication -> URL Configuration:
- Site URL: http://localhost:5173
- Additional Redirect URLs: http://localhost:5173

STEP 6 - RUN LOCALLY
--------------------
Terminal 1:
cd backend
.venv\Scripts\activate
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000

Terminal 2:
cd frontend
npm install
npm run dev

Open http://localhost:5173
Create account -> email confirm (if enabled) -> sign in -> test interview.

STEP 7 - PRIVACY TEST
---------------------
1. Student Account A create pannunga. Interview complete pannunga.
2. Sign out.
3. Student Account B create pannunga.
4. B account history-la A interview varakoodathu.
5. B account-ku A interview ID therinjaalum direct URL/API use panni access panna mudiyakoodathu.

Only after this test passes, deploy publicly.

NOTE:
- This integration adds login and owner-scoped history.
- Public deployment-ku before: rate limits, abuse protection, privacy notice and final CORS origin set pannunga.
